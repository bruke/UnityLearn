## 1. 建议规范（可直接当检查表）

### 1.1 命名

- Address：`模块/名字`，稳定，不进路径
- Group：`Local_Boot`、`Remote_Level01`、`Shared_Art`、`HotfixDll`
- Label：`boot` `level_01` `lang_zh` `hotfix`

### 1.2 路径

- 至少两个 Profile：`Dev`（Hosting / 内网）、`Release`（CDN）
- CDN 目录带平台：`/aa/<appVer>/<BuildTarget>/`
- `ServerData` 与 `addressables_content_state.bin` 纳入发版归档

### 1.3 打包

- 切换平台后 Clean + New Build
- Player Build 前确认刚打过对应平台的 Addressables
- Analyze Duplicate 作为 CI 可选步骤（失败则阻断或发警告）

### 1.4 运行时

- AOT 启动场景只依赖 Local
- 统一封装 Load/Release，禁止业务满天飞字符串且不 Release
- 远程失败有重试、有离线兜底文案

## 2. CI 要点

```
切 BuildTarget
选 Release Profile
Addressables Build（New 或 Content Update）
上传 ServerData/<Target> 到 CDN
Build Player
上传安装包
```

Content Update 任务要能取到 **上一版** `content_state.bin`。用 Git LFS 或对象存储按 `1.2.0/Android/addressables_content_state.bin` 保存。

## 3. 排错清单

| 现象 | 先查 |
|------|------|
| InvalidKeyException | Groups 里是否有该 Address；Play Mode 是否 Existing Build 却没打过包；Catalog 是否旧 |
| 编辑器正常、真机没有 | 是否一直 Asset Database；真机 Profile 是否还是 localhost；HTTPS / ATS |
| 404 | CDN 是否上传 hash/json/bundle；LoadPath 与目录是否差一层文件夹；平台目录是否 Android vs iOS 用错 |
| CRC mismatch | 上传不完整、CDN 缓存了旧文件、清客户端 Cache 再下 |
| 一直下载 | Catalog 每次 Build 全变；Bundle 没开哈希命名导致文件名不变内容变却缓存错（少见，仍建议哈希命名） |
| 内存只增不减 | 未 Release；Instantiate 只用 Destroy |
| 贴图粉红 / Shader 错 | 变体没进包；Shader 重复或未进 Local；剥离级别 |
| 场景重复加载报错 | 既在 Build Settings 又 Addressable |
| 热更代码不生效 | DLL 未进新 Catalog；仍在用旧 Assembly；未重启逻辑 |
| Hosting 真机连不上 | 用局域网 IP 不是 127.0.0.1；防火墙端口 |

日志：`Addressables` 相关 `Debug.Log`、`handle.OperationException`、Charles / 抓包看 catalog URL。

## 4. 性能备忘

- 包数量 vs 包大小：Separately 太多则 IO/HTTP 次数爆炸
- LZ4 本地、LZMA 远程是常见组合，以真机耗时为准
- 同步 `WaitForCompletion` 远程加载会卡死主线程
- 启动只 Init + 下 boot Label，不要一次 Download 整个游戏
