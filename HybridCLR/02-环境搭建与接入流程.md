# 02 - 环境搭建与接入流程

## 学习目标
- 完成 HybridCLR 在项目中的完整接入
- 理解 IL2CPP 扩展包的作用和安装方法
- 掌握 HybridCLR 的初始化配置

---

## 1. 安装 HybridCLR 包

### 1.1 方式一：Package Manager 安装
```
Window → Package Manager → + → Add package from git URL

URL: https://github.com/focus-creative-games/hybridclr_unity.git
```

### 1.2 方式二：克隆仓库
```bash
git clone https://github.com/focus-creative-games/hybridclr_unity.git
# 放入项目 Packages/ 目录
# 或通过 Package Manager → Add from disk 选择 hybridclr_unity
```

### 1.3 版本对应关系（关键！）
| Unity 版本 | HybridCLR 版本 |
|-----------|----------------|
| 2019.4.x | 0.6.x |
| 2020.3.x | 1.x |
| 2021.3.x | 2.x / 3.x |
| 2022.3.x | 3.x / 4.x |
| Unity 6 | 4.x+ |

> **重要**：每个 Unity 版本需要对应的 IL2CPP 扩展包，版本不匹配会编译失败。

---

## 2. 安装 IL2CPP 扩展包

HybridCLR 需要修改 IL2CPP 生成的代码，因此要安装对应版本的扩展。

### 2.1 检查 IL2CPP 是否可用
```
Player Settings → Other Settings → Scripting Backend = IL2CPP
（必须使用 IL2CPP，不能用 Mono）
```

### 2.2 安装扩展包
```bash
# 方法一：命令行安装（Windows）
# 打开 cmd / PowerShell，执行：
dotnet tool install -g hybridclr_unity
hybridclr_unity install

# 方法二：菜单安装
# 打开 HybridCLR → Installer 窗口
# 点击 Install（会自动下载匹配版本的 IL2CPP 补丁）
```

### 2.3 手动安装（备用）
```
1. 从 HybridCLR Releases 下载对应 Unity 版本的 il2cpp 补丁
2. 找到 Unity 安装目录：Editor/Data/il2cpp/
3. 备份原文件
4. 将补丁解压覆盖到 il2cpp/ 目录
```

## 3. 工程配置

### 3.1 必须的设置
```
Player Settings:
  ├─ Scripting Backend: IL2CPP
  ├─ Api Compatibility Level: .NET Standard 2.1（推荐）
  ├─ 允许 "Allow 'unsafe' Code"（视项目需要）
  └─ 目标平台：iOS / Android / Standalone
```

### 3.2 HybridCLR 设置面板
```
菜单 → HybridCLR → Settings
```

| 配置项 | 说明 |
|--------|------|
| Hotfix Assemblies | 需要热更的程序集列表 |
| AOT Metadatas | 需要补充元数据的 AOT 程序集 |
| Preserved AOT Assemblies | 强引用的 AOT 程序集 |
| Stripping | 裁剪相关（按项目需求） |

### 3.3 HybridCLRSettings 配置文件
```csharp
// Assets/HybridCLRSettings.asset（可脚本生成）
using HybridCLR.Editor;

public static class HybridCLRConfig
{
    public static void Setup()
    {
        var settings = HybridCLRSettings.Instance;

        // 热更程序集
        settings.hotUpdateAssemblies = new List<string>
        {
            "HotFix",
            "GameLogic",
            "UI",
        };

        // AOT 元数据补充
        settings.aotMetaAssemblies = new List<string>
        {
            "mscorlib",
            "System",
            "System.Core",
            "UnityEngine.CoreModule",
        };
    }
}
```

## 5. 快速验证接入是否成功

### 5.1 最小热更测试
```csharp
// HotFix 程序集中的入口类
namespace HotFix
{
    public class Main
    {
        public static void Test()
        {
            UnityEngine.Debug.Log("HotFix running! " + 1 + 1);
        }
    }
}
```

```csharp
// AOT 侧调用
using System.Reflection;

public class Bootstrap : MonoBehaviour
{
    void Start()
    {
        // 1. 加载热更 DLL
        byte[] dllBytes = LoadDllFromBundleOrDisk();
        Assembly hotFixAsm = Assembly.Load(dllBytes);

        // 2. 调用入口方法
        var type = hotFixAsm.GetType("HotFix.Main");
        var method = type.GetMethod("Test");
        method.Invoke(null, null);
    }
}
```

### 5.2 验证点
- [ ] Console 能打印出 `HotFix running!`
- [ ] 修改热更 DLL 后重打，无需重新安装 App 即生效
- [ ] 热更代码中可以正常使用泛型、反射、async/await

## 6. 常见安装错误

| 错误 | 原因 | 解决 |
|------|------|------|
| `il2cpp.exe` 编译失败 | IL2CPP 扩展包未安装或版本不匹配 | 重新执行 `hybridclr_unity install` |
| 找不到 `HybridCLRSettings` | 未生成设置文件 | HybridCLR → Settings 生成 |
| `AOTGenericReferences` 生成失败 | 缺少引用程序集 | 检查 asmdef 引用完整 |
| 报 `MissingMethodException` | 补充元数据不完整 | 全量补充 mscorlib 等核心库 |
