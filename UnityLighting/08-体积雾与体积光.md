# 08 - 体积雾与体积光（Volumetric Fog / Volumetric Lighting）

## 学习目标

- 严格区分三种技术：**普通雾（Distance Fog）**、**后处理光轴（God Rays / Light Shafts）**、**真正的体积雾（Volumetric Fog，视线上积分）**
- 明确：**URP 默认没有 HDRP 那套完整 Volumetric Fog / Local Volumetric Fog / 体积云**
- 能在 URP 里用 Lighting 雾 + 后处理光轴解决问题；真正体积效果走 **Renderer Feature + 射线步进（Ray Marching）** 并会算性能账
- 能把体积阴影和 [阴影系统](/UnityLighting/07-阴影系统与Shadowmask) 连起来，避免「光轴穿墙」

Shader 积分思路与大气散射简化见 [高级光照与全局光照](/UnityShader/13-高级光照与全局光照)；噪声密度步进见 [Shader 实战案例合集](/UnityShader/14-Shader实战案例合集) 高级案例「体积云雾」。

---

## 适用条件与版本前提

官方功能对照（Unity 6 管线比较，摘要）：

| 能力 | Built-in | URP | HDRP |
|------|----------|-----|------|
| Linear / Exp / Exp2 距离雾 | 是 | 是（Graphics / Lighting 雾） | 模型不同，用 Fog Override |
| 本地体积雾、3D Density Mask | 否 | **否** | 是 |
| 体积材质（Shader Graph 驱动本地雾） | 否 | **否** | 是 |
| 雾散射 / 大气散射一体化 | 否 | **否**（需自研或资源） | 是 |
| 体积云（Volumetric Clouds） | 否 | **否** | 是 |
| VFX 体积雾输出 | 否 | **否** | 是 |

因此：教程、概念图、HDRP Volume 里的 **Fog → Volumetric Fog Enable**，**不能**当作 URP 勾一下就有的功能。Unity 6 URP 强化了 APV、Render Graph 等，**并未**把 HDRP 体积雾完整搬来。第三方 URP Fog Volume 资源 ≠ 引擎内置。

本讲默认：**URP 2022 LTS 与 Unity 6 URP** 都按「无完整原生体积雾」设计方案。

---

## 原理：三种完全不同的东西

### 1. 普通雾（距离雾）

片元阶段用相机距离或深度，把颜色 lerp 到雾色：

```
fogFactor = Linear / Exp / Exp2(distance)
color = lerp(fogColor, sceneColor, fogFactor)
```

**没有**沿视线累积密度，**没有**灯光在空气中的散射亮斑，也 **没有** 体积阴影。便宜，负责「远山发白、统一大气」。URP 在 **Window → Rendering → Lighting → Environment / Other Settings → Fog**（或 Graphics 默认雾，视版本）启用。

### 2. 后处理光轴

场景先画完。后处理根据 **太阳在屏幕上的位置** 和深度/亮度，沿径向做衰减模糊（典型：Occlusion Mask + Radial Blur）。

- 像从太阳拉出的「丁达尔」，但是 **2D 屏幕效果**
- 遮挡物只有「挡住太阳盘」时才形成条纹；侧向体积、绕过墙角的真实散射做不像
- 成本主要是全屏模糊 Pass，与 Shadow Map 步进无关

Bloom、Dirt Lens、简单 Radial Blur 都属于这一档，不要写成「体积雾」。

### 3. 真正体积雾 / 体积光

对每条视线（或视锥体素）做积分：

```
L = ∫ σ_s * Li(x) * T(x) * Phase(θ) dx
```

`Li` 常来自主光颜色 × **阴影采样**；`T` 是到相机的透过率。实现上常见：

- **Ray Marching：** 从近平面沿视线走 N 步，每步采密度与阴影（URP 自研主路）
- **视锥体素（Froxel）：** HDRP 体积雾常用，把视锥切成 3D 网格再打光 —— **这是 HDRP 路径，不是 URP 内置**

没有阴影项时，体积光会穿过实心墙，只能叫「发光雾」。

## 编辑器配置步骤

### A. 只做普通雾（所有 URP 项目先做）

1. Lighting 窗口启用 Fog，选 Linear（可控起止）或 Exponential
2. 雾色贴近天空地平线，避免角色发灰
3. 与 Tonemapping 一起调，勿在 LDR 下把雾拧到爆

### B. 后处理光轴（中低成本「体积感」）

1. URP Renderer 确认 **Post-processing** 开启
2. 场景 Volume：Bloom（低 threshold、适度 dirt）
3. 自研时：Renderer Feature 在 **AfterRenderingTransparents** 之后 Blit
   - Pass1：根据深度生成「太阳可见遮罩」
   - Pass2：朝太阳屏幕坐标径向模糊
   - Pass3：加到场景色（Additive / 按亮度）

太阳方向用主光 `forward`，不要写死。

### C. URP 自研体积雾（Renderer Feature + Ray Marching）

1. 新建 **ScriptableRendererFeature**，Enqueue 一个在透明之后、后处理之前的 Pass（或按合成需求调整）
2. 声明需要 **Depth**；若要体积阴影，主光阴影必须已渲染（见第 07 讲）
3. Shader：循环步进（示意，不是完整产品 Shader）：

```hlsl
// 示意：沿视线步进，乘主光阴影得到体积光
float3 vol = 0;
float transmittance = 1;
for (int i = 0; i < _Steps; i++)
{
    float3 p = rayOrig + rayDir * t;
    float density = saturate(fbm(p) * _Density); // 噪声见案例合集
    float shadow = MainLightRealtimeShadow(TransformWorldToShadowCoord(p));
    float3 inScatter = _LightColor.rgb * shadow * density * _Scattering;
    vol += transmittance * inScatter * stepSize;
    transmittance *= exp(-density * _Absorption * stepSize);
    t += stepSize;
}
```

4. 降成本：半分辨率 RT、交错偏移（蓝噪声）、时间抖动 + TAA、步数 8～24
5. **不要**在本专题复制上百行完整 Shader；产品级噪声、阴影过滤、Froxel 以案例合集与独立 Pass 为准

HDRP 工程：用 Volume **Fog** 勾选 Volumetric、调 Slice 数与 Distance，本地雾用 **Local Volumetric Fog** —— 与 URP 菜单 **不是同一套组件**。

## 关键参数（按技术分开记）

### 距离雾

| 参数 | 说明 |
|------|------|
| Mode Linear Start/End | 玩法视距内尽量少雾，End 对齐远裁或山体 |
| Density（Exp） | 指数雾很难在近处保持通透，过场电影慎用 |

### 后处理光轴

| 参数 | 说明 |
|------|------|
| 采样次数 / 模糊半径 | 条纹平滑度；移动端 6～12 tap |
| Occlusion 阈值 | 过低则满屏拉丝，过高则只有纯日盘才有轴 |
| Intensity | 先曝光后强度，避免 Bloom 再加倍 |

### Ray Marching 体积

| 参数 | 说明 |
|------|------|
| Steps | 质量与成本几乎线性；室内 16，远景 8 + 半分辨率 |
| Max Distance | 超过则退回距离雾，避免步进到无穷远 |
| Density / Absorption | 密度高要减步长，否则欠采样条带 |
| Phase（Henyey-Greenstein） | 控制朝太阳的「向前散射」峰值 |
| Shadow sampling | 关阴影=假体积光；开阴影必须算进 Shadow Map 带宽 |

## 实战方案

**手游白天野外：** 只要 Linear 雾 + 轻微 Bloom。不要上 Ray Marching。

**日落剪影、教堂窗户：** 后处理光轴足够；窗户要用深度挡住太阳盘。墙后不应出现轴 —— 若出现，是遮罩没做，不是「缺 HDRP 体积雾」。

**地下室光柱、尘埃里的聚光：** 这才需要真正体积。URP：半分辨率 Ray March + **仅主光**阴影；聚光体积光再加一支圆锥域判断，步数更狠地降。预算不够就改用粒子片 + 预烘焙光柱贴图。

**大世界：** 近处 16 步体积，远处切回距离雾。不要全图 64 步。

**与 APV：** APV 解决表面间接光，体积雾解决空气；二者独立。见 [APV](/UnityLighting/05-自适应探针体积APV)。

## 性能分档（移动 / PC）

| 档位 | 普通雾 | 光轴后处理 | 真体积（Ray March） |
|------|--------|------------|---------------------|
| 低端移动 | 开 | 关 | 关 |
| 高端移动 | 开 | 半分辨率、低 tap | 可选：半分辨率、8 步、无额外光、抖动 |
| PC | 开 | 全分辨率可用 | 半或全分辨率、16～32 步、主光阴影；勿上 HDRP 级 Froxel 却仍跑 URP 期望 |

粗账：全屏 1080p、32 步、每步 1 次阴影采样 ≈ 数千万次纹理 fetch，移动端很容易变成带宽瓶颈。**先半分辨率，再谈步数。**

HDRP 体积雾用 froxel，质量/性能曲线不同；从 HDRP 搬项目到 URP 时要 **降级方案**，而不是找同名勾选。

## 故障排查

| 现象 | 排查 |
|------|------|
| 以为开了体积雾其实只有灰雾 | 你开的是距离雾；URP 没有 HDRP 那个 Volumetric 勾选 |
| 光轴穿透建筑 | 后处理没做深度遮罩；或体积步进没采阴影 |
| 条带、层状 | 步数不足；加抖动 / 蓝噪声 / TAA；减 Max Distance |
| 全屏发白 | Intensity × Bloom × HDR 曝光叠乘；吸收系数过低 |
| 与 Lit 场景曝光不一致 | 体积 Pass 写在 Tonemap 后或前不一致；统一走同一色彩管线 |
| 编辑器有、真机无 | Feature 未打进该质量的 Renderer Asset；Shader 变体被剥 |
| 性能断崖 | 全分辨率 × 高步数 × 点光阴影；先降 RT 尺寸 |
