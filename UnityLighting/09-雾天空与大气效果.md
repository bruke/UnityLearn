# 09 - 雾、天空与大气效果

## 学习目标

- 能区分距离雾（Distance Fog）、高度雾（Height Fog）与体积雾（Volumetric Fog），并选对实现路径
- 会配置天空盒（Skybox）/ HDRI、环境光（Ambient）与太阳（Sun）方向，搭出可调的昼夜氛围
- 知道 URP 内置雾的能力边界，以及何时应改用后处理或 HDRP 大气

---

## 1. 原理

雾、天空、环境光是一套**环境光照（Environment Lighting）**，不是三套互不相干的特效。

```
太阳方向（主平行光）
    → 天空盒着色 / HDRI 采样
    → 环境光（SH / 梯度 / 颜色）
    → 雾色与密度（把远景压进大气）
```

### 1.1 距离雾（RenderSettings Fog）

Unity 全局雾写在渲染设置（Render Settings）里，URP 着色器通过 `MixFog` 在片元末尾混合。模式：

| 模式 | 公式直觉 | 观感 |
|------|----------|------|
| 线性（Linear） | `(end - z) / (end - start)` | 近处全清、远处硬切，好控可视距离 |
| 指数（Exponential） | `exp(-density * z)` | 近处就开始染，适合潮湿/霾 |
| 指数平方（Exponential Squared） | `exp(-(density * z)²)` | 近处更清、远处更快变浓 |

`z` 在 URP 中通常是**到相机的距离**（视距），不是世界高度。因此**内置雾不能单独做高度雾**。

### 1.2 高度雾的实现选择

| 路线 | 说明 | 适用 |
|------|------|------|
| 着色器高度项 | 在 `MixFog` 前用 `positionWS.y` 再乘一层衰减 | 地表薄雾、移动端 |
| 深度重建后处理 | 用深度纹理还原世界坐标，按高度/距离着色 | 全场景统一、透明物体需另处理 |
| 体积雾 | 见 [体积雾与体积光](/UnityLighting/08-体积雾与体积光) | 需要光轴、局部体积 |
| HDRP 雾（Fog）Volume | 带高度、各向异性、体积散射 | HDRP 项目 |

不要把「开了 Fog 勾选」误当成体积雾。URP **默认没有** HDRP 那套物理天空 + 体积大气。

### 1.3 天空、HDRI 与环境光

- 程序化天空盒（Procedural Skybox）：用太阳方向、大气厚度、天顶/地面色即时算天空。
- 立方体贴图 / 全景 HDRI：把拍摄的环境辐射写进天空，同时作为间接漫反射与反射的源。
- 环境光来源（Ambient Source）：天空盒（Skybox）会把天空卷积成球谐（SH）；渐变（Gradient）和单色（Color）更便宜、更可控。

太阳方向来自主平行光（Directional Light）。Lighting 窗口里的太阳源（Sun Source）决定程序化天空把哪盏灯当太阳；未指定时通常取最亮的平行光。

### 1.4 大气散射与昼夜

真实大气是瑞利散射（Rayleigh，蓝天）+ 米氏散射（Mie，日晕/霾）。URP 程序化天空只是**外观近似**。昼夜变化的最小闭环：

```
旋转太阳 → 天空变色 → 环境光变暗 → 雾色跟着变暖/变冷 → 反射探针是否刷新
```

完整 Shader 推导见 [高级光照与全局光照](/UnityShader/13-高级光照与全局光照)。自定义全屏实现可参考 [后处理效果](/UnityShader/06-后处理效果)。

## 2. 编辑器配置 / 落地步骤

菜单名随版本可能写为 **Window → Rendering → Lighting** 或 **Window → Rendering → Lighting Settings**。以窗口内 **Environment** 分区为准，不要死记固定路径。

### 2.1 打开距离雾（URP）

1. 确认项目为线性颜色空间（Linear），见 [渲染管线与光照能力](/UnityLighting/01-渲染管线与光照能力)。
2. Lighting → Environment → Fog：勾选，选 Linear / Exponential / Exponential Squared。
3. Linear 填 Start / End；指数类填 Density。Fog Color 尽量贴近地平线色，避免远山「一层灰膜」。
4. 确认场景材质使用 URP Lit / Shader Graph，且未剥离雾变体（`FOG_LINEAR` 等）。
5. 透明物体、粒子、自己写的着色器必须在片元里调用雾混合，否则会「穿雾」。

### 2.2 天空盒与 HDRI

1. Environment → Skybox Material：指定材质。
2. 程序化：Shader 选 `Skybox/Procedural`，调 Atmosphere Thickness、Sky Tint、Ground、Exposure、Sun。
3. HDRI：用 `Skybox/Cubemap` 或全景（Panoramic）着色器，贴图勾选 HDR，压缩选适合 HDR 的格式。
4. Ambient Source 选 Skybox 时，改天空后点 **Generate Lighting**（或自动生成），否则 SH 环境光仍是旧的。
5. Environment Reflections：控制默认反射立方体；精细反射用 [反射探针](/UnityLighting/06-反射探针ReflectionProbe)。

### 2.3 太阳与昼夜最小流程

1. 场景只留一盏主平行光作为太阳源。
2. 用时间参数旋转其 Transform（通常绕世界 X/Z），不要每帧改 Intensity 冒充日落。
3. 同步：Intensity / Color、Fog Color、Skybox Exposure、必要时 Ambient Intensity。
4. 全动态昼夜：**不要**指望一张烘焙光照贴图覆盖 24 小时；静态建筑用实时或混合，或按几个时段多套烘焙。
5. 反射：低频用环境立方体；需要镜面准确时按间隔刷新探针，而不是每帧。

### 2.4 HDRP 对照

HDRP 用体积（Volume）上的视觉环境（Visual Environment）指定天空类型：HDRI Sky、Physically Based Sky、Gradient Sky 等。雾是独立的 Fog 覆盖：可开体积雾、高度雾、天空雾。物理天空会把太阳、空气、行星半径算进散射，**不要把这套菜单搬去 URP 找**。

## 3. 关键参数

| 参数 | 作用 | 建议 |
|------|------|------|
| Fog Mode | 衰减曲线 | 玩法关卡用 Linear 控可视距离；氛围用 Exp2 |
| Fog Start / End | 线性雾起止 | End 对齐 Camera Far Clip，避免远裁更早于雾 |
| Fog Density | 指数雾浓度 | 小步调整，0.01 级差异就很明显 |
| Fog Color | 雾色 | 跟地平线/太阳色温，避免纯白或纯灰 |
| Skybox Exposure | 天空亮度 | 线性空间下略低于「看起来刺眼」 |
| Atmosphere Thickness | 程序化大气厚度 | 过大变火星橙，过小变塑料蓝 |
| Ambient Intensity / Source | 间接底光 | 夜晚优先 Gradient，避免天空盒过曝把室内提亮 |
| Sun Source | 哪盏灯驱动天空 | 必须唯一、稳定，切勿每帧换引用 |

高度雾自定义时至少暴露：基准高度、衰减厚度、雾色、与距离雾的混合权重。

## 4. 移动端 / PC 性能

| 档位 | 建议 |
|------|------|
| 移动低端 | Linear 雾 + 单色/渐变环境光；程序化天空或低分辨率立方体；关闭体积雾 |
| 移动中端 | Exp2 + 程序化天空；高度雾用廉价着色器项，不要全屏 Ray Marching |
| PC | HDRI 天空 + Skybox 环境光；距离雾或高度雾后处理；局部体积雾见第 08 篇 |
| HDRP PC | Physically Based Sky + Volume Fog；注意体积切片与屏幕分辨率 |

成本点：雾本身几乎只是片元里几次乘加；贵的是**天空 HDR 纹理带宽**、**每帧刷新反射**、以及后处理高度雾对深度纹理的依赖。透明物体开雾会增加变体，需在剥离列表里管住。移动端优先 `half` 精度雾因子，见 [Shader 性能优化](/UnityShader/07-Shader性能优化)。

## 5. 常见问题

| 现象 | 原因与处理 |
|------|------------|
| 勾了 Fog 但物体不变 | 自定义 Shader 未 `multi_compile_fog` / 未 `MixFog`；或 Fog 变体被剥离 |
| 天空不进雾 | 预期行为。要用后处理对天空采样，或 HDRP 天空雾 |
| 透明物体像贴纸浮在雾上 | 透明 Pass 没混雾，或深度写入导致雾因子错误 |
| 高度不变、只有远近变白 | 你用的是距离雾。加 `positionWS.y` 或换后处理 |
| 改天空环境光不变 | Ambient Source = Skybox 但未重新 Generate Lighting |
| 昼夜时室内闪一下 | 探针/环境立方体瞬时替换。做过渡混合或降低刷新频率 |
| 雾色发灰脏 | Gamma 工作流或 Fog Color 与天空脱节。改线性并跟色温 |
| 程序化天空太阳和灯光错位 | Sun Source 指错灯，或平行光旋转轴不是「东升西落」 |
