# 11 - 屏幕空间光照效果

## 学习目标

- 抓住 SSAO / SSR / SSGI / 接触阴影（Contact Shadows）的**共同前提**：只用当前画面的深度与法线
- 能分清 URP **原生有什么、没有什么**，避免把 HDRP Volume 项当成 URP 开关
- 会按质量档组合效果，并解释「画面外缺失、镜面闪烁、漏光」从哪来

---

## 1. 原理：屏幕空间共性

屏幕空间（Screen Space）效果在**已经画完的缓冲**上近似光照，不追真实光线。

```
不透明渲染
    → 深度纹理（Camera Depth Texture）
    → 法线纹理（DepthNormals / GBuffer Normal）
    → 可选颜色（Opaque Color / Color Pyramid）
    → 全屏 Pass：沿屏幕射线步进
```

共性限制：

1. **画面里没有的几何不存在**：屏幕外、被挡住的物体无法参与遮蔽/反射/反弹。
2. **依赖深度精度**：远平面过大、Reverse Z 理解错误、MSAA 与深度解析冲突，都会出条纹和漏光。
3. **透明物体通常缺席**：玻璃、粒子多数不写这些缓冲。
4. **时域稳定差**：相机一转，新露出的区域要过几帧才「长出来」（TAA / 历史缓冲能缓解，也会拖影）。

这与全屏后处理同一套输入，实现骨架见 [后处理效果](/UnityShader/06-后处理效果)。全局光照的「真」方案（探针、光照贴图、光线追踪）见 [高级光照与全局光照](/UnityShader/13-高级光照与全局光照)。

### 1.1 四种效果分别近似什么

| 效果 | 近似目标 | 典型输入 | 失败时的样子 |
|------|----------|----------|--------------|
| 屏幕空间环境光遮蔽（SSAO） | 缝隙里的间接阴影 | 深度 + 法线 | 物体描边、远处噪点、角色脖子一圈黑 |
| 屏幕空间反射（SSR） | 光滑表面反射 | 深度 + 颜色金字塔 + 粗糙度 | 天空盒硬切、角色走近镜子才出现 |
| 屏幕空间全局光照（SSGI） | 一次反弹的间接光 | 深度 + 法线 + 颜色 | 色溢只存在于屏幕内，转头间接光跳变 |
| 接触阴影（Contact Shadows） | 接触处的短阴影 | 深度 + 光源方向 | 阴影短、离开接触面立刻消失；画面边缘缺影 |

它们都是「近处细节增强」，**不能替代**主阴影贴图、探针或烘焙。接触阴影尤其只补 Shadowmap 分辨率不够时的「脚贴地」缝。

## 2. URP 原生能力边界（对照 HDRP）

名称以你当前包里的 Renderer Feature / Volume 列表为准，Unity 版本之间会改名。

| 能力 | URP | HDRP |
|------|-----|------|
| SSAO | **有**：Renderer Feature「Screen Space Ambient Occlusion」 | Volume：Ambient Occlusion（SSAO / 射线追踪等） |
| 屏幕空间阴影（Screen Space Shadows） | 部分版本有 Feature，服务主光阴影采样，**不是** Contact Shadows | 有屏幕空间阴影相关项 |
| SSR | **默认没有**与 HDRP 同级的 Volume SSR。需自研 Feature、第三方包，或换 HDRP | Volume：Screen Space Reflection |
| SSGI | **不是** URP 通用原生功能。间接光走 [光照探针](/UnityLighting/04-光照探针LightProbe) / [APV](/UnityLighting/05-自适应探针体积APV) / 烘焙 | Volume：Screen Space Global Illumination |
| Contact Shadows | **无**内置。可用短距离屏幕射线自研，成本接近 SSAO | Volume：Contact Shadows |
| 射线追踪 AO/GI/反射 | 通常不考虑 | DX12/Vulkan 下可选 |

结论：**URP 项目把 SSAO 当标配增强；SSR/SSGI/接触阴影不要写进「勾选即用」的策划文档。** 需要完整屏幕空间间接光，优先评估 HDRP，而不是在 URP 里堆四个全屏 Pass。

Unity 大版本若后续为 URP 增加实验项，仍以 **该版本 HDRP/URP 文档与 Renderer Feature 列表**为准，不要用旧教程菜单硬找。

## 3. 编辑器配置 / 落地步骤

### 3.1 URP：打开 SSAO

1. 选中 URP Renderer，Add Renderer Feature → Screen Space Ambient Occlusion（名称可能略有差异）。
2. 确认相机或 Renderer 会生成深度；需要法线时打开 Depth Texture，并让 SSAO 使用 DepthNormals 源（若选项存在）。
3. 先用半分辨率（Half）+ 中等采样数跑通，再谈全分辨率。
4. 把 Intensity 降到「缝里有脏、平面没有灰雾」；After Opaque 时机避免透明被错误加深。
5. 角色单独一层：过强 SSAO 会让脸部眼窝、衣服褶皱脏成泥。可用更小 Radius，或对第一人称武器关闭。

### 3.2 若必须在 URP 做 SSR / 接触阴影

1. 走自定义 Renderer Feature：重建世界坐标 → 沿反射向量或光线方向步进深度 → 命中则采样 Opaque Texture。
2. 限制：只对 Smoothness 高于阈值的像素；限制最大步进次数；失败时回退反射探针。
3. 接触阴影步进要**短**，只补接触缝，不要当主阴影。
4. 完整体积/GI 仍应回到探针与烘焙，而不是把 SSGI 当移动端方案。

### 3.3 HDRP 对照（Volume）

1. 场景有全局 Volume + HDRP 配置文件启用对应效果。
2. Ambient Occlusion、Screen Space Reflection、Screen Space Global Illumination、Contact Shadows 按质量档逐项开。
3. SSR 设质量、边缘淡出、天空回退；SSGI 设反弹次数/分辨率（以当前版本字段为准）。
4. 与射线追踪同时开时，明确谁处理「屏幕内」、谁处理「屏幕外」，避免双重间接光。

## 4. 关键参数

| 参数（概念） | 作用 | 建议 |
|--------------|------|------|
| Intensity | 效果强度 | SSAO 宁弱勿脏 |
| Radius / Max Ray Length | 搜索半径 | 大半径更「全球」，更噪、更贵 |
| Sample Count / Ray Steps | 质量 | 移动端 4～8；PC 再加 |
| Downsample | 半/四分辨率 | 移动端默认半分辨率 |
| Direct Lighting Strength（若有） | 遮蔽是否乘直接光 | 室内可略开，室外慎开 |
| Edge Fade / Screen Fade | 屏幕边缘淡出 | SSR/SSGI 必开，减少「框外消失」硬切 |
| Thickness / Depth Bias | 命中厚度 | 过薄漏反射，过厚物体互相粘连 |
| Min Smoothness | SSR 门槛 | 只让真正光滑的表面进 SSR |

深度/法线来源选错时，调上述参数都像「在噪声上叠加噪声」。先用 Frame Debugger 确认 `_CameraDepthTexture` / 法线 Pass 存在。

## 5. 适用组合与质量档

| 档位 | URP | HDRP |
|------|-----|------|
| 移动低端 | 全关；靠烘焙 AO、主光阴影 | 一般不选 HDRP |
| 移动中端 | 半分辨率 SSAO，小 Radius | — |
| PC 中端 | 全分辨率 SSAO；反射靠探针 | SSAO + 低质量 SSR |
| PC 高 | SSAO + 自研/包 SSR（仅高光滑） | SSAO + SSR + Contact Shadows |
| 影视/高配 | 评估换 HDRP | 再加 SSGI；屏幕外靠探针或 RT |

**不要**在 URP 上同时开 SSAO + 全屏 SSR + 伪 SSGI + 接触阴影：四次全屏步进会把 GPU 打满，画面却仍缺屏幕外信息。组合原则：

- 先阴影贴图与探针（稳）。
- 再 SSAO（便宜的缝细节）。
- 反射：探针为主，SSR 为辅。
- SSGI / 接触阴影：HDRP 或高配 PC 再谈。

性能剖析手法见 [Shader 性能优化](/UnityShader/07-Shader性能优化) 与 [渲染优化与工程实践](/UnityLighting/12-渲染优化与工程实践)。雾与天空不要用 SSGI 代替，见 [雾、天空与大气效果](/UnityLighting/09-雾天空与大气效果)。

## 6. 常见问题

| 现象 | 原因与处理 |
|------|------------|
| 物体一圈黑描边 | SSAO Radius 过大或法线来源与深度不一致 |
| 转相机间接光闪 | 屏幕外信息缺失。加边缘淡出、历史缓冲，或换探针 |
| 镜子里没有身后物体 | SSR 正常限制。用探针/平面反射补 |
| 玻璃没有 AO/反射 | 透明未写入深度。单独处理或放弃屏幕空间 |
| 开了 MSAA 效果碎 | 深度解析与多样本冲突。URP 常用 TAA 替代 MSAA |
| 找得到 HDRP 的 SSGI 菜单，URP 没有 | 能力边界，不是安装坏了 |
| 接触阴影和 Shadowmap 叠成双影 | 缩短 Contact 距离，或降低主光阴影 Bias 后关接触阴影 |
| 全屏 Pass 比场景还贵 | 降分辨率、减步进、减同时开启的效果数 |

## 7. 学习检查点

- [ ] 能用「深度+法线、画面外不存在」解释四种效果的共同缺陷
- [ ] 能准确说出 URP 原生主要是 SSAO，SSR/SSGI/Contact Shadows 不能当 URP 标配
- [ ] 能配出可用的半分辨率 SSAO，并处理角色描边过黑
- [ ] 能按移动/PC 档给出「开哪些、用探针补哪些」的组合，而不是全开
